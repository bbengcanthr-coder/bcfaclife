# 岁月长歌 — บันทึกกาลเวลา

เกมจำลองชีวิตจีนโบราณแบบเล่นบนเว็บ เหมาะกับหน้าจอโทรศัพท์ ใช้ HTML/CSS/JavaScript ปกติ ไม่มี build step และนำขึ้น GitHub Pages ได้

## วิธีเล่นในเครื่อง
- เปิด `index.html` ในเบราว์เซอร์ หรือใช้ Live Server ใน VS Code
- กด “เริ่มต้นชะตาชีวิต” เพื่อสุ่มชื่อ เพศ ตระกูล ฐานะ และสุขภาพ
- กดผ่านปีทีละปี หรือเปิดเดินเวลาอัตโนมัติ (ประมาณ 8 วินาทีต่อปี)
- เลือกทางชีวิตเมื่อมีเหตุการณ์ และดาวน์โหลดบันทึกชีวิตเป็น JSON
- ปุ่มเพลงจะเปิดเพลง MP3 ประกอบ (เบราว์เซอร์มักต้องให้ผู้ใช้กดก่อนจึงเล่นเสียงได้)

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด `index.html`, `style.css`, `game.js` และโฟลเดอร์ `assets/`
3. ไปที่ **Settings → Pages** เลือก branch `main` และ folder `/ (root)` แล้ว Save
4. เปิด URL ที่ GitHub Pages แสดง

## หมายเหตุ
- นี่เป็นเกมต้นแบบเชิงเรื่องเล่า ไม่ใช่แบบจำลองประวัติศาสตร์หรือการพยากรณ์จริง
- ภาพประกอบเป็นภาพต้นฉบับที่สร้างสำหรับโปรเจกต์นี้ เพลงเป็นทำนองสังเคราะห์แนว pentatonic เบา ๆ เพื่อให้มีไฟล์ MP3 พร้อมใช้
- ฟอนต์ออนไลน์ใช้ Google Fonts หากออฟไลน์จะ fallback เป็นฟอนต์ในระบบ
