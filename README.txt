浮生录 · บันทึกชีวิตล่องลอย

ไฟล์ในชุดนี้
- index.html : เกมเว็บแบบ responsive สำหรับโทรศัพท์และเดสก์ท็อป
- fushenglu_bgm.mp3 (หรือ WAV หากระบบนี้ไม่มีตัวแปลง MP3): เพลงบรรเลงต้นฉบับแบบสังเคราะห์โทนสงบ

วิธีเปิดเล่น
1. แตก ZIP
2. เปิด index.html เพื่อทดสอบในเบราว์เซอร์
3. อัปโหลด index.html และไฟล์เพลงไปไว้ใน repository GitHub เดียวกัน
4. เปิด Settings > Pages แล้วตั้ง source ให้ deploy จาก branch ที่เก็บไฟล์ (เช่น main / root)

หมายเหตุ
- ปุ่มเพลงเปิดเสียงสังเคราะห์ในหน้าเว็บได้โดยตรง เพราะเบราว์เซอร์มักต้องให้ผู้ใช้แตะก่อนเล่นเสียง
- ไฟล์เพลงแยกให้ด้วย สามารถนำไปใช้เป็นเพลงประกอบต่อได้
- เวอร์ชันนี้เป็นต้นแบบเล่นได้ มีเหตุการณ์และตัวเลือกจำลอง; ยังไม่ใช่เกมเชิงประวัติศาสตร์ที่ตรวจสอบข้อเท็จจริงทุกยุค
- ฟอนต์ภายนอกอาจต้องใช้อินเทอร์เน็ต; เกมหลักทำงานแบบ static บน GitHub Pages
